## GPU-телеметрия

Источник: `gemma4-12b-iq3xs-full-gpu-20261021-172242.csv`; 367 последовательных измерений примерно раз в секунду (2026/10/21 17:22:42.670 — 2026/10/21 17:28:49.679).

| GPU-показатель | Значение |
|---|---:|
| Power Limit (в каждой записи) | 120.00 W |
| Температура в начале → максимум | 28 → **62 °C** |
| Занято VRAM — максимум | **6035 / 6144 МиБ (98.23%)** |
| Резерв VRAM при максимуме | **109 МиБ** |
| Peak power.draw | **132.40 W** |
| Медиана power.draw при GPU memory ≥ 4000 МиБ | 112.15 W |
| Среднее power.draw при GPU memory ≥ 4000 МиБ | 96.04 W |
| Средняя utilization.gpu при GPU memory ≥ 4000 МиБ | 97.1% |
| Записей с power.draw > 120 W | 55 из 367 |

Для средних по занятой GPU использованы 329 замеров с выделенными ≥4000 МиБ VRAM, что захватывает также загрузку модели. `power.draw` — моментальные показания nvidia-smi, **не прямое измерение энергии на розетке**. Превышение 120 W в отдельных показаниях не свидетельствует о смене Power Limit; в каждой строке лимит остаётся 120 W.

VRAM достигает 6035 МиБ, свободный остаток лишь 109 МиБ: полный профиль `-ngl 99 --fit off -c 4096` технически прошёл все кейсы, но практически не имеет запаса по памяти для более длинного контекста или дополнительных одновременных процессов.
