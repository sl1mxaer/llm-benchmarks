## Производительность и GPU

- Полное процессное время (15 кейсов): 232.16 с; среднее: 15.48 с.
- Средняя скорость prompt: 324.33 ток/с; генерации: 20.35 ток/с.
- Peak resident set size по `/usr/bin/time -v`: 5392004 kB (около 5.14 GiB), это **RAM, не VRAM**.
- GPU CSV: 248 измерений, пик VRAM 5413 MiB из 6144 MiB, пик температуры ядра 58 °C.
- Установленный предел мощности 120 Вт, максимум наблюдённого `power.draw` 136.88 Вт; 42 посекундных показаний выше 120 Вт. Это не эквивалент измерению устойчивого среднего или потребления из розетки.
- Средняя зарегистрированная мощность при `VRAM > 500 MiB` 93.99 Вт, включает переходы загрузки/простоя и не является чистой мощностью генерации.
- Поведение VRAM и GPU utilization согласуется с активным CUDA-вычислением, но `-ngl 99` — запрошенный offload, число фактически перенесённых слоёв в имеющихся логах не подтверждено.
