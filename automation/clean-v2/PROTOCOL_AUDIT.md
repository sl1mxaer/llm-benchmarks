## Результаты и пределы оценки

Каждая модель: [полный report.md](results/README.md) с RAW/эталоном/ответом и оценкой; исходная таблица scores.csv из 15 ручных оценок; GPU CSV. Исходники таблиц имели **разные заголовки**; для общего анализа создан отдельный ALL_CASE_SCORES_NORMALIZED.csv, не смешивать с оригинальными CSV.

Файлы scores.csv в GitHub представлены с сохранением всех 15 строк, баллов и комментариев, но приведены к стабильному CSV-экспорту (UTF-8 BOM / CRLF), поскольку передача выполнялась через текстовый файловый коннектор. **Байтовые оригиналы** CSV, девять первоначальных архивов ZIP и GPU CSV находятся в локальном архиве передачи CLEAN_v2_ALL_9_MODELS_HANDOFF_2026-10-21.zip и в прежних чатах. Сами веса GGUF в GitHub не добавлялись.

Технический exit=0 не означает качественный CLEAN. DeepSeek-R1 генерировала рассуждения до лимита токенов; её 24.89 t/s не означает скорость генерации готовой очистки. RSS из GNU time — RAM, VRAM определяется по отдельному GPU CSV. Показания nvidia-smi кратковременно выше 120 W не означают смену Power Limit. Параметры -ngl 99 --fit off -c 4096 нельзя менять и сохранять тот же скоростной профиль. Температура генерации 0.7 без seed означает стохастичность; небольшие различия баллов требуют повторений.

Баг сохранения ZIP в PTY-раннере: run_dir.with_suffix(".zip") сокращает имя при точке в названии модели; использовать только напечатанный путь "Архив для отправки:". Не исправлять версию на сервере до окончания сопоставимых тестов.
