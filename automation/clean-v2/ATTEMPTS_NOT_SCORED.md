# CLEAN v2 — попытки без полной оценки (22.10.2026)

Это **не строки рейтинга** и не нулевые баллы. При frozen профиле с P106-100 6 GiB, `llama.cpp b11338-dcd387a41`, `-ngl 99 --fit off -c 4096 -ctk f16 -ctv f16` полноценные 15-кейсовые серии не выполнялись.

| GGUF | SHA-256 (локально) | Smoke | Статус | Причина |
|---|---|---|---|---|
| YandexGPT 5 Lite 8B IQ3_M | `e8833a0254ee77747683ef9cf34c7a002bfa03b76c3d70ea91179432a11578a6` | GPU с системным промптом, CPU с системным промптом, GPU без системного промпта | **SMOKE_FAILED / INVALID_OUTPUT** | При проверке генерировался бессмысленный текст вместо `ГОТОВО`; контрольная Q4_K_M отвечала корректно. 15-кейсового запуска нет |
| Gemma 4 12B IT IQ3_M | `def80efba2f976bb0c9709f06845b237ba3092bf4d68d5b47fd84b4ef23f4439` | GPU `SMOKE_EXIT=1` | **VRAM_LIMIT / NOT_TESTED** | При выделении GPU KV cache на **480.00 MiB** получено `cudaMalloc failed: out of memory`; контекст создать не удалось |

Дополнительно **Qwen3-4B Q4_K_M** и **Qwen3.5-4B Q4_K_M** исключены из **новой серии CLEAN v2 по решению пользователя**, а не из-за технического отказа. Их прежние исторические GPU/CPU испытания не смешиваются с этими 15-кейсовыми GPU v2.

Версия **Gemma 4 12B IT IQ3_XS** успешно прошла серию (98/120), но это **другая квантовка**, не замена неудавшейся IQ3_M.

Решение: не уменьшать `-ngl`, `-c` и KV datatype в общем сравнении, поскольку это сформировало бы иной скоростной профиль. Исходные GGUF не добавляются в GitHub; логи smoke — в переписке с автором.
