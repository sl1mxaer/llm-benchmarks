# Исходные файлы новых 10 моделей — опубликованы

**Полная публикация завершена.** Исходные бинарные ZIP всех десяти новых прогонов хранятся в [`source-archives/`](source-archives/README.md) с исходными именами, побайтно идентичные пользовательским вложениям. К каждому ZIP приложена контрольная сумма SHA-256 в [`source-archives/SHA256SUMS.txt`](source-archives/SHA256SUMS.txt). Контрольные Git blob SHA-1 совпали с исходными объектами при переносе.

В каталогах [`results/16-…` — `results/25-…`](results/README.md) опубликованы оригинальные **ежесекундные GPU CSV** (сравнение по Git SHA-1 подтвердило идентичность), `responses.json`, `scores.csv`, `gpu-summary.csv`, `report.md` с текстами RAW / REFERENCE / RESPONSE и комментариями ко всем 150 кейсам. Сводные файлы — [25-модельный индекс](RESULTS_INDEX.csv), [375 покейсных оценок](ALL_CASE_SCORES_NORMALIZED.csv), [150 измерений задержки/скорости](NEW_CASE_METRICS_10_MODELS.csv) и [реестр имён источников](NEW_RUN_SOURCE_ARCHIVES_2026-10-22.csv).

**Границы публикации:** веса моделей GGUF не добавлялись (1,6–5,1 ГБ на файл); для первых 15 исторических моделей исходные ZIP и их статус хранения описаны в историческом аудите. Бинарные ZIP новых 10 хранятся в GitHub; к ним можно обращаться независимо от чатов. Четыре компонентные ручные оценки 0–2/кейс для новых десяти моделей не были сохранены отдельно — в CSV они оставлены пустыми, но оценки /8 и HF сохранены. Aya: 8 смысловых hard failures и отдельный дефект суффикса в 15/15 ответах.
