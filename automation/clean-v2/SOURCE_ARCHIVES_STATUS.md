## Исходные десять ZIP — отдельный этап публикации

Бинарные исходные ZIP каждого из десяти новых прогонов (по ~70–80 КиБ; `manifest.json`, `run.log`, `metrics.csv`, исходные материалы/ответы, параметры и прочее) сохранены пользователем в исходных вложениях. Коннектор GitHub, использованный для этого обновления, принимает содержимое текстовых файлов, но не исходные бинарные ZIP напрямую. **В GitHub эти десять ZIP пока не опубликованы.**

Для их загрузки подготовлен отдельный комплект `CLEAN_v2_NEW_10_ORIGINALS_2026-10-22.zip` с 10 ZIP, 10 исходными CSV, `SHA256SUMS.txt` и безопасным скриптом `PUBLISH_SOURCES_WINDOWS.ps1`. Этот комплект выдаётся в соответствующем диалоге ChatGPT как скачиваемый файл. После распаковки скрипт проверяет хеши и создаёт в GitHub каталог `automation/clean-v2/source-archives/`, сохраняя исходные ZIP побайтно.

Весовые файлы моделей GGUF намеренно не архивируются в репозиторий.

### Методические примечания

Исходная серия 15 моделей остаётся исторически неизменной. Новые десять результатов оценены на той же шкале /120 (15 кейсов, 8 баллов максимум на кейс), hard failures отмечены отдельно. Ранее выставлялся единый балл /8 за кейс; отдельные четыре оценки /0–2 в разговоре не сохранялись и потому не реконструируются искусственно. `Aya Expanse`: 8 смысловых HF, плюс служебный токен в 15/15 фактических ответах.
